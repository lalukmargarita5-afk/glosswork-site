# CLAUDE.md

Сайт детейлинг-студии **GLOSSWORK**. Подробности о проекте: `README.md`, о студии и правилах контента: `PRODUCT.md`, о дизайне: `DESIGN.md`.

## Как со мной работать

- Общаться только на русском, кратко, без воды, по пунктам. Описания команд тоже на русском.
- Всегда работать через **graphify**: если есть `graphify-out/`, сначала смотреть граф (`graphify-out/GRAPH_REPORT.md`, `graph.json`). Команда `/graphify` вызывает скилл graphify.
- Когда останется около 10% токенов, остановиться и предупредить.
- Для дизайна и вёрстки использовать скилл **impeccable**: дизайн-система в `.impeccable/design.json`, бриф главной в `.impeccable/surfaces/index-html.md`.
- Ничего не выдумывать: никаких фейковых отзывов, цен, гарантий и цифр (см. `PRODUCT.md`).

## Что где лежит

- `index.html`, `styles.css`, `main.js`, `privacy.html`, `assets/`: исходники сайта, без сборки.
- `google-script-zayavki.gs`: приём заявок через Google Apps Script (Google Таблица + письмо).
- `сайт-для-публикации/`, `GLOSSWORK-сайт-целиком.html`, `GLOSSWORK-архив-проекта-*.zip`: собранные копии сайта для выкладки. Пересобираются из исходников, в git не входят.
- `skills/`: zip-архивы всех моих скиллов, по одному на скилл. Нужны для переезда на новый аккаунт или компьютер.
- `.claude/launch.json`: локальный сервер для предпросмотра (`python -m http.server 5173`).
- Сайт на Timeweb (https://lalukmargarita5-afk-glosswork-site-66f8.twc1.net) обновляется из ветки `main` на GitHub.
- При каждом изменении `styles.css` или `main.js` поднимать метку версии `?v=ГГГГММДД` в `index.html` и `privacy.html`, иначе браузеры покажут старую версию из кэша.
- Репозиторий на GitHub публичный, личное и служебное перечислено в `.gitignore`.

## Переезд на новый аккаунт или компьютер

Полный набор для переезда (скиллы, агенты, настройки, память, история диалогов, архивы проектов was и pramen-dental, скрипт `ВОССТАНОВИТЬ-ВСЁ.bat`) собран 25.11.2026 в `Desktop\ПЕРЕЕЗД-CLAUDE`, инструкция там же: `00-ИНСТРУКЦИЯ-ЧИТАТЬ-ПЕРВОЙ.txt`. Если папка есть, а скиллов нет, предложи пользователю запустить этот bat.

Если ты (Claude) открыл эту папку впервые на новом аккаунте, проверь и сделай:

1. **Скиллы.** Проверь, есть ли скиллы в `~/.claude/skills/` (например `~/.claude/skills/graphify/SKILL.md`). Если их нет, распакуй каждый архив из `skills/*.zip` в `~/.claude/skills/`, чтобы получилось `~/.claude/skills/<имя>/SKILL.md`. Уже существующие папки не перезаписывай без спроса. После распаковки попроси пользователя начать новую сессию, чтобы скиллы подхватились.
2. **Плагины с аккаунта.** Их нет в архивах, пользователь включает их сам в настройках Claude: **spec-pilot** и **anthropic-skills** (docs, pdf, docx, xlsx, pptx, deep-research, skill-creator и другие). Напомни об этом.
3. **Коннекторы (MCP).** Пользователь подключает их заново сам: Higgsfield (генерация картинок и видео), Claude Docs, Claude in Chrome. Напомни.
4. **Графики.** Если `graphify-out/` устарел или отсутствует, пересобери граф скиллом graphify.
5. **Git.** Проверь `git status` и `git log`: история работы над сайтом хранится там.

Встроенные команды (code-review, simplify, run, loop, schedule и т.д.) идут вместе с Claude Code, их ставить не нужно.

Старые диалоги на новый аккаунт не переносятся: они хранятся в `~/.claude/projects/`, а не в этой папке. Всё важное о проекте записывать сюда, в `PRODUCT.md` или `DESIGN.md`, а не держать только в чате.
